# Employee Management System

A full-stack Employee Management System built using HTML, CSS, JavaScript, Node.js, Express.js, and PostgreSQL.

This application allows users to add, view, update, delete, search, and filter employee records.

---

## Features

- Add new employees
- View all employees
- Update employee details
- Delete employees
- Search employees
- Filter employees by department
- Dashboard with employee statistics
- Total salary calculation
- Average salary calculation
- Form validation
- Duplicate email validation
- Error handling
- PostgreSQL database integration
- Responsive user interface
